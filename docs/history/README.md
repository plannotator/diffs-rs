# Experiment records

These files are dated plans, reports, censuses, and reviews from the experiments that produced
the current viewer. They record what was measured or decided at the time and are kept for
provenance. They are not current status, instructions, or open tasks.

For the current state, start with the [README](../../README.md) and
[CURRENT_STATE.md](../../CURRENT_STATE.md).

Some records cite evidence outside this repository:

- `evidence/` paths refer to large local corpora and captures. That directory is ignored by Git.
- External records, temporary verification directories (`/var/folders/...`), and other absolute
  paths refer to the original workstation. They are not in this repository and may no longer exist.
